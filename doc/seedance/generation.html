视频模型

doubao-seedance-2.0 视频生成(Seedance 原生格式)

Seedance 视频生成采用 v3 异步任务协议：先调用 POST /api/v3/contents/generations/tasks 创建任务，再用 GET /api/v3/contents/generations/tasks/{task_id} 查询结果。请求体使用 content 数组承载文本、参考图、首尾帧、参考视频和参考音频。

可选模型

model说明
doubao-seedance-2.0标准版，适合通用视频生成场景，质量和速度均衡。
doubao-seedance-2.0-fast快速版，适合对生成速度要求更高的场景。
doubao-seedance-2.0-mini轻量版，适合成本敏感或快速预览场景。

功能分类

文生视频

只提供文本提示词生成视频。你可以直接修改 model、content、duration、ratio、resolution 等参数。

示例：

{
  "model": "doubao-seedance-2.0-mini",
  "content": [
    {
      "type": "text",
      "text": "清晨池塘上的纸船，电影感镜头推进"
    }
  ],
  "duration": 5,
  "ratio": "16:9",
  "size": "16:9",
  "resolution": "720p",
  "width": 1280,
  "height": 720,
  "n": 1,
  "generate_audio": false,
  "metadata": {
    "ratio": "16:9",
    "resolution": "720p",
    "watermark": false
  }
}
POST /api/v3/contents/generations/tasks
提交后返回任务 ID，用下方“查询任务结果”继续查询。

参考图生视频

用一张参考图约束主体、构图或人物形象。参考图放在 content 中，类型为 image_url，角色为 reference_image。

示例：

{
  "model": "doubao-seedance-2.0-mini",
  "content": [
    {
      "type": "text",
      "text": "让画面产生轻微运镜，人物自然眨眼，真实摄影风格"
    },
    {
      "type": "image_url",
      "role": "reference_image",
      "subject_type": "person",
      "image_url": {
        "url": "https://example.com/person.jpg"
      }
    }
  ],
  "duration": 5,
  "ratio": "16:9",
  "size": "16:9",
  "resolution": "720p",
  "width": 1280,
  "height": 720,
  "n": 1,
  "generate_audio": false,
  "metadata": {
    "ratio": "16:9",
    "resolution": "720p",
    "reference_image_url": "https://example.com/person.jpg",
    "input_mode": "reference_content"
  }
}
POST /api/v3/contents/generations/tasks
把 image_url.url 换成公网可访问的图片地址。

首帧图生视频

提供视频首帧图片并生成后续动作。首帧图片使用 role: "first_frame"，适合从固定起始画面开始生成视频。

示例：

{
  "model": "doubao-seedance-2.0-mini",
  "content": [
    {
      "type": "text",
      "text": "人物抬头看向镜头，镜头缓慢推进，保持起始构图稳定"
    },
    {
      "type": "image_url",
      "role": "first_frame",
      "image_url": {
        "url": "https://example.com/start.jpg"
      }
    }
  ],
  "duration": 5,
  "ratio": "16:9",
  "size": "16:9",
  "resolution": "720p",
  "width": 1280,
  "height": 720,
  "n": 1,
  "generate_audio": false,
  "metadata": {
    "ratio": "16:9",
    "resolution": "720p",
    "first_frame_url": "https://example.com/start.jpg",
    "input_mode": "first_frame"
  }
}
POST /api/v3/contents/generations/tasks
把 image_url.url 换成公网可访问的首帧图片地址。

首尾帧图生视频

指定视频第一帧和最后一帧，让模型生成中间过渡。首帧使用 role: "first_frame"，尾帧使用 role: "last_frame"。

示例：

{
  "model": "doubao-seedance-2.0-mini",
  "content": [
    {
      "type": "text",
      "text": "从白天城市街道平滑过渡到夜晚霓虹街景"
    },
    {
      "type": "image_url",
      "role": "first_frame",
      "image_url": {
        "url": "https://example.com/day.jpg"
      }
    },
    {
      "type": "image_url",
      "role": "last_frame",
      "image_url": {
        "url": "https://example.com/night.jpg"
      }
    }
  ],
  "duration": 5,
  "ratio": "16:9",
  "size": "16:9",
  "resolution": "720p",
  "width": 1280,
  "height": 720,
  "n": 1,
  "generate_audio": false,
  "metadata": {
    "ratio": "16:9",
    "resolution": "720p",
    "first_frame_url": "https://example.com/day.jpg",
    "last_frame_url": "https://example.com/night.jpg",
    "input_mode": "first_last_frame"
  }
}
POST /api/v3/contents/generations/tasks
使用首尾帧时，不要同时加入参考图、参考视频或参考音频。

参考视频

用一个参考视频约束运动节奏或画面动态。参考视频放在 content 中，类型为 video_url。

示例：

{
  "model": "doubao-seedance-2.0-mini",
  "content": [
    {
      "type": "text",
      "text": "参考视频的运动节奏，生成真实摄影风格的新画面"
    },
    {
      "type": "video_url",
      "role": "reference_video",
      "video_url": {
        "url": "https://example.com/reference.mp4"
      }
    }
  ],
  "duration": 5,
  "ratio": "16:9",
  "size": "16:9",
  "resolution": "720p",
  "width": 1280,
  "height": 720,
  "n": 1,
  "generate_audio": false
}
POST /api/v3/contents/generations/tasks
把 video_url.url 换成公网可访问的视频地址。

参考视频 + 参考音频

同时提供参考视频和参考音频，常用于人物说话、口型或节奏参考。音频使用 type: "audio_url"。

示例：

{
  "model": "doubao-seedance-2.0-mini",
  "content": [
    {
      "type": "text",
      "text": "人物说话场景，口型和节奏参考音频，画面参考视频运动"
    },
    {
      "type": "video_url",
      "role": "reference_video",
      "video_url": {
        "url": "https://example.com/reference.mp4"
      }
    },
    {
      "type": "audio_url",
      "role": "reference_audio",
      "audio_url": {
        "url": "https://example.com/speech.wav"
      }
    }
  ],
  "duration": 11,
  "ratio": "16:9",
  "size": "16:9",
  "resolution": "720p",
  "width": 1280,
  "height": 720,
  "n": 1,
  "generate_audio": true
}
POST /api/v3/contents/generations/tasks
把视频和音频 URL 换成公网可访问地址。

查询任务结果

创建任务后会返回 id。将该任务 ID 填入下面输入框，查询生成进度和结果。

示例：

curl https://api.huanxing.ai/api/v3/contents/generations/tasks/task_01KMCGF6BQGN3X28H3KSR50X5T \
  -H "Authorization: Bearer sk-你的令牌"
GET /api/v3/contents/generations/tasks/{task_id}
任务完成后，响应中通常会包含视频 URL。

响应示例

创建任务成功后，响应会在顶层 id 字段返回公开任务 ID。

{
  "id": "task_xxxxxxxxxxxxxxxxxxxxxxxx",
  "model": "doubao-seedance-2.0-mini",
  "status": "queued",
  "created_at": 1783355337
}

任务成功后查询响应使用 succeeded 状态，并在 content.video_url 返回视频地址：

{
  "id": "task_xxxxxxxxxxxxxxxxxxxxxxxx",
  "model": "doubao-seedance-2.0-mini",
  "status": "succeeded",
  "content": {
    "video_url": "https://example.com/result.mp4"
  }
}

失败响应格式

视频任务失败分为两类：任务本身生成失败，以及本次轮询接口调用失败。两者的 HTTP 状态和返回结构不同，请不要只根据 message 文案判断。

场景HTTP 状态固定错误码处理建议
成功查到任务，但任务生成失败200VIDEO_GENERATION_FAILED任务已进入失败终态，停止轮询。
本次没有成功查询到任务状态502VIDEO_POLL_FAILED任务结果仍未知，可稍后重试轮询。

任务生成失败

轮询请求本身成功，并且上游明确返回任务生成失败。接口返回 HTTP 200，任务状态为 failed：

{
  "id": "task_xxxxxxxxxxxxxxxxxxxxxxxx",
  "model": "doubao-seedance-2.0",
  "status": "failed",
  "content": {},
  "error": {
    "message": "The request was rejected by content moderation",
    "code": "VIDEO_GENERATION_FAILED",
    "upstream_code": "CONTENT_POLICY_VIOLATION"
  }
}
任务生成失败的含义：查询接口正常返回了任务终态，只是视频生成没有成功。调用方应停止轮询，并将任务记录为生成失败。

轮询接口失败

SeedDanceAPI 本次没有成功取得任务状态，例如上游查询超时、网络错误、鉴权失败、返回非 2xx 或响应无法解析。接口统一返回 HTTP 502：

{
  "error": {
    "message": "task_not_exist",
    "type": "server_error",
    "param": null,
    "code": "VIDEO_POLL_FAILED",
    "upstream_code": "task_not_exist"
  }
}
轮询接口失败的含义：本次任务状态未知，不等于视频已经生成失败。调用方不应把任务直接标记为 failed，可按重试策略稍后继续查询。

错误字段说明

字段是否固定说明
error.code是任务生成失败固定为 VIDEO_GENERATION_FAILED；轮询接口失败固定为 VIDEO_POLL_FAILED。
error.message否具体错误原因，由服务端根据实际失败情况返回。
error.upstream_code否可选的原始错误码，仅用于问题排查。服务端未提供时不会返回该字段。
error.type轮询失败固定轮询接口失败时为 server_error；任务失败对象不要求该字段。
error.param轮询失败固定轮询接口失败时为 null，表示错误不对应某个请求参数。

以上格式对所有视频生成任务统一生效。调用方应以固定的 error.code 判断失败阶段，upstream_code 仅用于日志记录和问题排查。

请求参数

参数类型必填说明
modelstring是可选 doubao-seedance-2.0、doubao-seedance-2.0-fast、doubao-seedance-2.0-mini。
contentarray是多模态内容数组，至少包含一个有效的 text 项；也可加入图片、视频或音频项。
durationnumber否视频时长，单位秒。常用值为 5，建议范围 3 到 15，实际可选值以模型能力为准。
ratio / sizestring否画面比例，例如 16:9、9:16、1:1、4:3、3:4。建议两个字段保持一致。
resolutionstring否分辨率，例如 480p、720p、1080p，默认按渠道能力处理。
width / heightnumber否输出宽高。16:9 常用 1280x720，9:16 常用 720x1280。
nnumber否生成视频数量，通常为 1。
generate_audioboolean否是否同时生成音频；设为 false 时也会原样传递，不会因零值被省略。
metadataobject否扩展参数，可放置 ratio、resolution、watermark、输入模式及参考素材 URL。

content 内容项

type主要字段说明
texttext文本提示词。创建任务时至少提供一段非空文本。
image_urlrole、image_url.urlrole 可使用 reference_image、first_frame 或 last_frame。
video_urlrole、video_url.url参考视频，通常使用 role: "reference_video"。
audio_urlrole、audio_url.url参考音频，通常使用 role: "reference_audio"。
