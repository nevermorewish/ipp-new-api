Cursor 接入

接入方式：Cursor 可以通过 OpenAI API Key 与 Override OpenAI Base URL 使用寰星云科的 OpenAI 兼容接口。

前置准备

  • 已在寰星云科控制台创建 default 分组 API 令牌。
  • 已确认 Cursor 中要启用的模型名称与寰星云科模型广场中的名称一致。
  • 配置后如果已有 Cursor 窗口没有生效，可以重启 Cursor 再测试。

配置 Models

  1. 打开 Cursor 设置，进入 Models 页面。
  2. 在模型列表中启用需要使用的模型；如果需要自定义模型，点击 Add Custom Model 后填写模型名。
  3. 展开 API Keys 区域，启用 OpenAI API Key，并填入寰星云科 API 令牌。
  4. 启用 Override OpenAI Base URL，把默认 URL 替换为 https://api.huanxing.ai/。

推荐填写值

配置项 填写内容 说明
OpenAI API Key sk-****** 填写寰星云科控制台创建的 API 令牌。
Override OpenAI Base URL https://api.huanxing.ai/ 按 Cursor 的 OpenAI 覆盖地址输入框填写。
模型名称 claude-opus-4-8 示例模型名，可换成实际可用模型。

注意：Cursor 的模型开关只决定客户端是否展示该模型；实际能否调用成功，还取决于 API Key 所在分组是否开放对应模型。
