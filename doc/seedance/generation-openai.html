视频模型

doubao-seedance-2.0 视频生成(openai格式)

本接口使用 OpenAI 兼容的 JSON 请求格式。先调用 POST /v1/video/generations 创建异步视频任务，再调用 GET /v1/video/generations/{task_id} 查询生成状态和结果。

接口地址：请求域名使用当前寰星云科 API 地址；请求头必须携带 Authorization: Bearer sk-你的令牌 和 Content-Type: application/json。

可选模型

model说明
doubao-seedance-2.0标准版，适合通用视频生成场景，质量和速度均衡。
doubao-seedance-2.0-fast快速版，适合对生成速度要求更高的场景。
doubao-seedance-2.0-mini轻量版，适合成本敏感或快速预览场景。

创建视频任务

POST /v1/video/generations
提交成功后会返回任务 ID，请使用下方查询接口轮询。

请求参数

参数类型必填说明
modelstring是模型名称，可选 doubao-seedance-2.0、doubao-seedance-2.0-fast 或 doubao-seedance-2.0-mini。
promptstring是视频生成提示词，不能为空。建议描述主体、动作、环境、镜头运动和画面风格。
durationinteger否视频时长，单位秒。常用值为 5，建议范围 3 到 15，实际可选值以模型能力为准。
secondsstring否duration 的 OpenAI 兼容别名，例如 "5"。请勿与 duration 同时提供；同时提供时 seconds 优先。
sizestring否画面比例或输出尺寸，例如 16:9、9:16、1280x720、720x1280。
resolutionstring否输出分辨率，例如 480p、720p、1080p。未提供时默认按渠道能力处理。
input_referencestring否单个参考图片 URL，用于图生视频。必须是上游可访问的公网地址。
imagesstring[]否参考图片 URL 数组。若只使用一张图片，优先使用 input_reference。
image_urlsstring[]否Seedance 参考图片 URL 数组，用于图生视频或参考素材。不能与 image_with_roles 同时使用。
referenceVideosstring[]否参考视频 URL 数组，用于约束生成视频的主体动作、镜头运动或画面节奏。字段名区分大小写。
referenceAudiosstring[]否参考音频 URL 数组，可与 referenceVideos 同时使用，用于声音、说话节奏或口型参考。字段名区分大小写。
generate_audioboolean否是否为生成的视频保留或生成音频。参考音频场景通常设为 true；显式传入 false 时也会原样发送给上游。
image_with_rolesobject[]否带用途的图片数组。每项包含 url 和 role；role 可使用 first_frame 或 last_frame 指定首帧、尾帧。
first_frame_imagestring否首帧图片 URL。用于图生视频时指定视频起始画面。
last_frame_imagestring否尾帧图片 URL。与 first_frame_image 一起使用时指定视频结束画面。
modestring否渠道扩展的生成模式；没有明确需求时可省略。
metadataobject否渠道扩展参数，可放置 ratio、resolution、watermark 等配置。
参数提示：image_urls 与 image_with_roles 不能同时提供。首尾帧可以使用 image_with_roles 的 role 字段，也可以使用 first_frame_image / last_frame_image 字段；请不要重复提供相互冲突的图片。参考视频和参考音频必须是 SeedanceAPI 上游可访问的地址。duration、size、resolution、音频生成和参考素材的可用组合可能因模型版本而不同。请求被拒绝时，请先使用文生视频的最小请求验证模型和令牌，再逐项增加可选参数。

请求示例

文生视频

curl https://api.huanxing.ai/v1/video/generations \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2.0",
    "prompt": "清晨池塘上的纸船，电影感镜头缓慢推进，水面泛起微光",
    "duration": 5,
    "size": "16:9",
    "resolution": "720p"
  }'
POST /v1/video/generations
提交后返回任务 ID，用下方查询接口继续查询。

使用 image_urls 参考图生视频

curl https://api.huanxing.ai/v1/video/generations \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2.0",
    "prompt": "人物自然眨眼并看向镜头，轻微运镜，真实摄影风格",
    "image_urls": ["https://example.com/person.jpg"],
    "duration": 5,
    "size": "16:9",
    "resolution": "720p"

参考视频 + 参考音频生成视频

同时提供参考视频和参考音频，可让生成结果参考输入视频的动作与运镜，并参考音频的说话节奏、声音或口型。下面示例会创建一个有声视频任务。

curl https://api.huanxing.ai/v1/video/generations \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2.0-mini",
    "prompt": "人物自然说话，参考视频中的动作和镜头运动，并匹配参考音频的说话节奏",
    "referenceVideos": [
      "https://example.com/reference.mp4"
    ],
    "referenceAudios": [
      "https://example.com/speech.wav"
    ],
    "duration": 11,
    "size": "16:9",
    "resolution": "720p",
    "generate_audio": true
  }'
POST /v1/video/generations
请把参考视频和参考音频 URL 换成 SeedanceAPI 上游可访问的地址。

创建响应

创建成功后，响应顶层的 id 是公开任务 ID。请保存该值用于后续查询。

{
  "id": "task_xxxxxxxxxxxxxxxxxxxxxxxx",
  "model": "doubao-seedance-2.0",
  "status": "queued",
  "created_at": 1783355337
}

查询任务结果

GET /v1/video/generations/{task_id}
状态为 succeeded 时，响应中会返回视频地址。

任务完成后的响应示例：

{
  "id": "task_xxxxxxxxxxxxxxxxxxxxxxxx",
  "model": "doubao-seedance-2.0",
  "status": "succeeded",
  "content": {
    "video_url": "https://example.com/result.mp4"
  }
}

任务状态

status说明处理方式
queued任务正在排队。稍后继续查询。
in_progress视频正在生成。稍后继续查询。
succeeded生成成功。读取 content.video_url。
failed生成失败。停止轮询并读取 error。

失败响应格式

参数错误、鉴权失败或服务异常使用统一错误对象。任务本身生成失败时，查询响应的 status 为 failed，并包含具体错误信息。

{
  "error": {
    "message": "model field is required",
    "type": "invalid_request_error",
    "param": "model",
    "code": "missing_model"
  }
}

任务生成失败时，查询接口仍会返回任务对象，并使用固定错误码：

{
  "id": "task_xxxxxxxxxxxxxxxxxxxxxxxx",
  "model": "doubao-seedance-2.0",
  "status": "failed",
  "error": {
    "message": "Video generation failed",
    "code": "VIDEO_GENERATION_FAILED"
  }
}
