WorkBuddy 接入

接入方式：WorkBuddy 支持 OpenAI 兼容协议的自定义 API。配置时使用寰星云科接口地址、你的 API Key，以及要调用的模型名称。

前置准备

  • 已在寰星云科控制台完成 创建 API 令牌。
  • 令牌分组建议选择 default，并确认目标模型在该分组可用。
  • 本文示例模型为 claude-opus-4-8，也可以替换为模型广场中实际开放的模型名。

添加自定义模型

  1. 打开 WorkBuddy，在对话输入框附近点击当前模型名称，展开模型列表。
  2. 在模型列表底部找到 配置自定义模型，进入模型设置页面。
  1. 在“添加模型”弹窗中，供应商选择 自定义 / Custom。

填写接口信息

按下方内容填写后保存：

配置项 填写内容 说明
提供商 自定义 / Custom 使用 WorkBuddy 的 OpenAI 兼容自定义 API 配置。
接口地址 https://api.huanxing.ai 按 WorkBuddy 当前配置入口填写根地址。
API Key sk-****** 填写你在寰星云科创建的 API 令牌。
模型名称 claude-opus-4-8 可替换为模型广场中当前可用的模型名。

配置完成后：回到对话界面，在模型下拉列表中选择刚添加的自定义模型，发送一条简单消息测试是否能正常回复。
