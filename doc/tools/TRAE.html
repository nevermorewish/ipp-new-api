TRAE 接入

接入方式：TRAE 的“添加模型”支持自定义配置。选择自定义配置后，填写寰星云科接口地址、API Key 和模型名即可。

前置准备

  • 已在寰星云科控制台创建 API 令牌，建议使用 default 分组。
  • 已确认要填写的模型名在当前令牌分组可用。
  • 本文示例模型为 claude-opus-4-8。

进入添加模型

  1. 打开 TRAE，在输入框右侧或模型下拉菜单中展开当前模型列表。
  2. 点击底部的 添加模型。

选择自定义配置

  1. 在“添加模型”窗口中找到 自定义配置。
  2. 展开自定义配置，并填写接口信息。

填写接口信息

配置项 填写内容 说明
接口地址 https://api.huanxing.ai 使用寰星云科 API 根地址。
API Key sk-****** 填写在寰星云科创建的 API 令牌。
模型名称 claude-opus-4-8 可替换为模型广场中当前可用的模型名。

保存后测试：回到 TRAE 对话页，选择刚添加的模型发送测试消息。如果提示模型不存在或无可用渠道，优先检查模型名和令牌分组。
