Seedance Material Library

素材库 API

素材库 API 用于创建和管理素材组、完成真人认证，以及上传、查询和删除素材文件。

接口地址

POST https://api.huanxing.ai/api/material?Action=<Action>

所有接口使用 Bearer Token 鉴权，请求体为 JSON。

统一响应格式

所有素材库接口均使用 ResponseMetadata 和 Result 包装响应。业务错误位于 Result.Error。

{
  "ResponseMetadata": {
    "RequestId": "sys-...",
    "Action": "GetAsset",
    "Version": "2024-01-01",
    "Region": "cn-beijing"
  },
  "Result": {
    "Id": "asset-example-id",
    "Status": "Active"
  }
}

素材组

CreateAssetGroup — 创建素材组

创建一个虚拟素材组。Name 必填，Description 可选。

POST /api/material?Action=CreateAssetGroup

ListAssetGroups — 查询素材组列表

查询当前令牌可访问的素材组列表。无需请求参数；素材组数据和可能的分页信息由上游返回在 Result 中。

POST /api/material?Action=ListAssetGroups

GetAssetGroup — 查询素材组

通过素材组 ID 查询名称、描述、类型和创建时间等信息。

POST /api/material?Action=GetAssetGroup

DeleteAssetGroup — 删除素材组

通过素材组 ID 删除素材组。

POST /api/material?Action=DeleteAssetGroup

真人认证

CreateVisualValidateSession 用于创建真人素材组；CreateAssetGroup 用于创建虚拟素材组，请按素材类型选择。

CreateVisualValidateSession — 创建真人认证会话

请求参数均为可选。可通过 Url 指定认证完成后的回调地址；该参数仅用于火山引擎认证会话，并会转换为火山原生字段 CallbackURL。响应包含 BytedToken、H5 认证链接和二维码。完成认证后，使用 BytedToken 查询结果。

POST /api/material?Action=CreateVisualValidateSession

GetVisualValidateResult — 查询真人认证结果

使用创建认证会话时返回的 BytedToken 查询。建议每 3 秒查询一次，最长查询 5 分钟。

POST /api/material?Action=GetVisualValidateResult

CreateRealValidateH5 — 创建真人认证管理页面

无需请求参数。响应中的 Result.H5Link 是真人认证与素材管理页面地址，Result.ExpiresIn 表示有效期；小于或等于 0 表示长期有效。

POST /api/material?Action=CreateRealValidateH5

素材文件

CreateAsset — 上传素材

从可公开访问的 HTTP(S) URL 创建素材。AssetType 支持 Image、Video 和 Audio。

POST /api/material?Action=CreateAsset

GetAsset — 查询素材

通过素材 ID 查询名称、URL、类型、所属素材组和处理状态等信息。

POST /api/material?Action=GetAsset

DeleteAsset — 删除素材

通过素材 ID 删除素材。

POST /api/material?Action=DeleteAsset

在视频生成中使用素材

素材状态为 Active 后，可用 asset://<素材 ID> 引用素材。

{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "image_url",
      "image_url": { "url": "asset://asset-example-id" },
      "role": "reference_image"
    },
    { "type": "text", "text": "让图中的猫动起来，在草地上奔跑" }
  ],
  "resolution": "720p",
  "duration": 5
}

常见错误

Error.Code说明
InternalError服务暂时不可用，请稍后重试。
InvalidRequest请求参数缺失或格式不正确。
AccessDeniedAPI 令牌无权访问该资源。
ResourceNotFound指定的素材组或素材不存在。
LimitExceeded请求频率过高，请降低调用频率。
