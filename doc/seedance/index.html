Video Models

视频模型教程

视频模型采用异步任务模式：提交请求后返回任务 ID，再通过任务状态接口轮询生成进度与结果。Seedance 同时提供原生格式和 OpenAI 兼容格式：原生格式使用 content 数组传入多模态内容，兼容格式使用 prompt 及参考素材参数。

doubao-seedance-2.0 视频生成(Seedance 原生格式)

使用 /api/v3/contents 异步任务协议，支持文生视频、参考图、首尾帧、参考视频、参考音频与有声视频。

doubao-seedance-2.0 视频生成(openai格式)

使用 /v1/video/generations JSON 接口，通过 prompt 创建并查询视频任务。

素材库 API

连接 SeedDanceAPI，管理虚拟人像与真人人像素材，并在线试用素材接口。
